JS Week 11 - ES6 Modules

Files:
- index.html: page that displays the result
- utils.js: contains two custom utility functions and exports them
- main.js: imports and uses both functions

The two tools:
1. calculateTotal(price, taxRate = 0.1): calculates the price after tax.
2. formatPrice(amount, currency = "USD"): formats a number as currency.

How to run:
Open index.html using a local server (for example, VS Code Live Server), because JavaScript ES6 modules may not work correctly when opening the file directly.
